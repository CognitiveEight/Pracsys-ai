Key Directories:
----------------
app/socket/          - Socket.IO client, schemas, per-feature handler mixins
app/langgraph/       - Role gate, chat, strategy, dates, timeline, drafting graphs
app/prompts/         - Legal prompts, one module per feature + shared guardrails
app/search/          - Indian Kanoon + Vertex AI Search retrieval
app/ai/              - Gemini client
app/processing/      - Document/audio ingestion, OCR, DOCX generation
app/vectorstore/     - Qdrant documents + state caches
app/workspace/       - Workspace state, persistence, custom instructions
app/storage/         - Google Cloud Storage helpers
app/core/            - Config, lifecycle, security
app/observability/   - Logging, audit, tracing


External Dependencies:
----------------------
- Socket.IO Server (Required — the app backend; this service is a CLIENT)
- Google Gemini (LLM - primary; GOOGLE_API_KEY, model via GEMINI_MODEL)
- Qdrant (Vector store; QDRANT_URL)
- Redis (Caching - optional)
- Google Vertex AI Search (optional fallback; GCP_PROJECT_ID +
  VERTEX_SEARCH_DATA_STORE_ID — replaced Google CSE)
- GCP Vision / Speech-to-Text V2 / GCS (optional: OCR, audio diarization;
  GCS_BUCKET_NAME + ffmpeg on PATH for full diarization)

Configuration:
--------------
Environment: .env file (copy from env.example; never commit)
Settings: app/core/config.py
Validation: Pydantic Settings


Key Features:
-------------
✓ Socket.IO client with auto-reconnection and reconnect-safe payload caches
✓ Role-gated multi-agent pipeline (no downstream agent runs without a role)
✓ Document embedding and semantic search per workspace (Qdrant)
✓ Audio evidence transcription with speaker diarization
✓ Strategy & objective, analysis report + quality score, list of dates
✓ Procedural timeline (court/law procedural dates only)
✓ Applicable laws (Indian Kanoon + Vertex AI Search, BNS/BNSS/BSA — no IPC)
✓ Case laws: source-verified precedents with clickable judgment links,
  manual add (citation/URL/text) and upload verification
✓ Relevant parties: role-badged party directory with per-document provenance
✓ Drafting assistant: lawyer-scoped template library, multi-draft % matching,
  confirm-every-variable kickoff, 64k long-form render
✓ Chat-driven panel editing (surgical name/term/date/year edit vs
  objective-change regeneration with panel preservation)
✓ Dual-track legal reasoning (civil + criminal where applicable)
✓ Output guardrails: English-only, Title Case, brand scrub, current-year
  anchoring for dateless source dates
✓ Comprehensive logging, audit trails, distributed tracing
✓ Type-safe with Pydantic; async/await throughout


Development Tools:
------------------
make setup          - Complete setup (venv, deps, .env, folders)
make run            - Start application
make docker-up      - Start services (Qdrant, Redis)
make lint / format  - pylint / black (if installed)

exist — validate via make run against a connected backend.)
